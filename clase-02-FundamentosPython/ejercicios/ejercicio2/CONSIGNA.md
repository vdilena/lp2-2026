# Ejercicio 2 — Cantidad de alumnos aprobados

## Objetivo

Obtener la cantidad de alumnos aprobados del final de los alumnos de un curso. Se debe crear una lista de alumnos donde cada alumno tiene la informacion del nombre, apellido, email, nota final. Tener en cuenta que para aprobar el final, se necesita una nota mayor o igual a 4.
