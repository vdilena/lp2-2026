# Ejercicio 4:
Un pequeño comercio necesita analizar las ventas realizadas durante una jornada.  
Al comenzar, el programa debe solicitar cuántas ventas se realizaron durante el día.  
Por cada venta se deberá ingresar el importe correspondiente.  
Una vez cargadas todas las ventas, el programa deberá informar:

* La cantidad de ventas realizadas.
* La recaudación total.
* El importe promedio de las ventas.
* La mediana de ventas
* La moda de las ventas
* La venta de mayor importe.
* La venta de menor importe.
* Cuántas ventas superaron el promedio diario.
* Los importes que superaron dicho promedio.
* Ordenar las ventas del mayor a menor precio

Además, el comercio considera como ventas importantes aquellas cuyo importe sea exactamente alguno de los siguientes valores:50000, 100000 o 200000.
Y como ventas poco importantes a las que sean menores a 20000.

Para cada venta cargada, indicar si su importe pertenece al conjunto de ventas importantes definido por el comercio. 
Por último se pide obtener un listado con las ventas importantes y no importantes.
