# Ejercicio 3
Se dispone de un archivo estudiantes.csv con la siguiente información:
```
nombre,edad,nota
Ana,22,8
Juan,25,6
Lucia,21,9
Pedro,24,4
Maria,23,7
```
Crear un programa que lea el archivo y muestre:
* El nombre y la nota de cada estudiante.
* La cantidad total de estudiantes.
* El promedio general de las notas.
* Los nombres de los estudiantes que obtuvieron una nota igual o superior a 7.
